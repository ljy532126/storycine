演员库 ​

演员库是创作流程的第 3 步，管理角色、场景、道具的资产和 AI 生图。

三个标签页 ​

标签内容生图模式
角色名称 / 类型 / 性别 / 年龄 / 外貌 / 性格 / 背景三视图角色卡
场景名称 / 描述场景图
道具名称 / 描述道具图

角色详情（双栏布局） ​

┌───────────────────────────┬──────────────────────────┐
│  角色名称 / 类型性别年龄   │  生图提示词              │
│  外貌描述                 │  构建提示词 / AI润色     │
│  性格特征                 │  [提示词 textarea]        │
│  背景故事                 │  模型选择 | 画幅比例      │
│  [移除] [保存修改]        │  [生成角色图]            │
│                           │  参考图预览               │
└───────────────────────────┴──────────────────────────┘

快捷操作 ​

一键生图 ​

在左侧卡片列表上方点击「一键生图」，为所有待生成的资产批量提交生图任务。

上传参考图 ​

hover 角色卡片 → 出现「上传图片」按钮 → 上传参考头像。

批量移除 ​

勾选多张卡片 → 点击「批量移除」。

AI 生成提示词 ​

点击「AI 润色」让 AI 根据外貌描述优化提示词。 点击「构建提示词」自动拼接标准四格角色设定卡提示词。
