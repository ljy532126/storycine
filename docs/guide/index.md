# StoryCine 使用教程

StoryCine 是一款端到端的 AI 短剧创作工具。从灵感到成片，覆盖**剧本生成 → 分镜设计 → AI 生图/生视频 → 成片合成**全流程。

## 工作流概览

整个创作流程分为 5 个步骤，对应工作台的 5 个标签页：

```
① 剧本工坊 → ② 分镜台本 → ③ 演员库 → ④ 镜头板 → ⑤ 成片合成
```
