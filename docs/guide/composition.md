# 成片合成

成片合成是创作流程的第 5 步，负责**将分镜素材合成为完整视频**。

## 合成配置

| 选项 | 说明 |
|---|---|
| 选择分镜表 | 从已同步的分镜表中选择 |
| 输出格式 | MP4 / MOV / AVI |
| 分辨率 | 1080x1920 (竖屏) / 1920x1080 (横屏) |
| 帧率 | 12-60 fps |
| 转场效果 | 淡入淡出 / 剪切 / 滑动 / 叠加 |
| 背景音乐 | URL 链接（可选） |
| 字幕 | 开关 |

## 操作流程

1. 确保「**镜头板**」中已有生成好的图片/视频素材
2. 选择分镜表
3. 配置合成参数
4. 点击「**开始合成**」
5. 在右侧任务列表中查看进度
6. 完成后点击「**下载成片**」

## 任务状态

| 状态 | 说明 |
|---|---|
| 等待中 | 任务已提交，排队等待 |
| 渲染中 | 正在合成视频 |
| 已完成 | 合成完毕，可下载 |
| 失败 | 合成出错，查看错误信息 |

## 合成引擎

合成使用 **真实 FFmpeg** 引擎：
- 支持图片序列 → 视频
- 支持视频片段拼接
- 支持添加背景音乐
- 支持字幕叠加
