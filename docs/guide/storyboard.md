# 镜头板

镜头板是创作流程的第 4 步，负责**批量生图 / 生视频**。

## 界面布局

```
┌─ 刷新故事板 ─ 删除 ─ [导出] [导入] ─ 无字幕 ─ 帮助 ─┐
├────────┬─────────────────────────────┬────────────────┤
│  剧集  │    预览区                   │  右侧详情       │
│  列表  │  图片/视频播放              │  提示词编辑     │
│        │  镜头信息                   │  模型选择       │
│        │                             │  参考角色       │
│        │                             │  生成按钮       │
├────────┴─────────────────────────────┴────────────────┤
│  分镜时间线 (可拖拽排序)                               │
│  批量生图 ─ 批量生视频                               │
│  [缩略图] [缩略图] [缩略图] [缩略图] ...               │
└──────────────────────────────────────────────────────┘
```

## 核心功能

### 刷新故事板
从剧本重新生成故事板（调用 AI 分镜 Agent）。

### 批量生图
为所有待定分镜批量提交生图任务，可多选参考角色提高一致性。

### 批量生视频
为已有图片的分镜批量生成视频。

### 单个分镜编辑
点击时间线中的缩略图，右侧面板可编辑：
- **图片提示词**（imagePrompt）
- **视频提示词**（videoPrompt）
- **模型选择**（Seedance / Kling / 通义）
- **参考角色**（支持角色一致性约束）

### 拖拽排序
时间线中的分镜支持拖拽重排。
