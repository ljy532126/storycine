# 管理员功能

以下功能仅 **管理员（admin）** 账号可用。


## 用户管理

路径：左侧菜单「**用户管理**」

- 查看所有用户列表（含统计：活跃数 / 今日新增 / 管理员数）
- 创建新用户
- 启用 / 禁用 / 封禁用户
- 重置用户密码
- 查看用户登录日志（IP / 地理位置 / 登录结果）

## 公告管理

路径：左侧菜单「**公告管理**」

- 创建公告（支持 Markdown）
- 设置公告类型：通知 / 提醒 / 好消息 / 重要
- 设置目标：所有用户 / 仅管理员
- 公告会自动推送给在线用户（右上角铃铛通知）

## 错误日志

路径：左侧菜单「**错误日志**」

- 自动捕获所有 API 错误
- 按状态码 / 路径 / 用户筛选
- 详情弹窗：请求体 / Query / Headers / Stack Trace
- **AI 分析**：点击弹窗中的 AI 分析按钮，自动分析错误原因
- 批量标记已处理 / 清空已处理

## 存储设置

路径：「**系统设置**」→ 对象存储标签

配置对象存储（阿里云 OSS / 腾讯云 COS / MinIO），用于持久化图片/视频素材。
