# 创建第一个项目

## 1. 进入片场管理

点击左侧菜单「**片场管理**」，点「**新建片场**」。

输入项目名称，选择合适的导演风格（写实 / 动漫），点击确认。

![片场管理]()

## 2. 设置导演风格

创建片场后进入「**工作台**」，在顶部步骤栏选择「**分镜台本**」。

右侧面板可配置：
- **画面比例**：16:9（横屏）/ 9:16（竖屏）
- **风格参考**：28 种预设风格（写实 / 古风 / 赛博朋克 / 水墨风 等）
- **导演全局设定**：画质关键词 / 氛围光影 / 艺术风格

## 3. 开始创作

回到「**剧本工坊**」，选择题材标签（悬疑 / 言情 / 科幻...），点击「**AI 开写剧本**」。

AI 将通过 7 个 Agent 协作生成完整剧本：
```
标签解析 → 大纲 → 人物 → 剧情架构 → 撰写 → 校验 → 完成
```
