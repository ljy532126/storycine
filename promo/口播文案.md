你能想象，一个人，一台电脑，一天出一集成品短剧是什么体验吗？

**[正文 45 秒]**

这是一个 AI 短剧生成平台，我给它取名叫 StoryCine。你只需要选几个标签——什么题材、什么风格、多少集——然后点一下"生成"，它给你自动跑完整个流程：

第一步，7 个 AI Agent 同时开工，给你出剧本大纲；
第二步，自动拆出分镜脚本，连景别、运镜、光影全都给你安排好；
第三步，AI 生图和生视频——角色图、场景图、道具图，统一风格，全部批量出；
第四步，自动合成，配上音乐，直接输出成品。

整个过程，你只需要做一件事：等着看。

这东西后台接入的是豆包 Seedream 4.0 生图、Seedance 2.0 生视频，也支持 DeepSeek 写剧本。28 种导演风格预设，写实、古风、赛博朋克、水墨风随便切。

你敢想吗？以前一个短剧工作室要养编剧、画师、剪辑师、配音师，一个片子要搞一周。现在你一个人，一杯咖啡的功夫，就能出一条完整的 AI 短剧。

**[结尾 10 秒]**

代码已经开源在 GitHub 上了，MIT 协议，随便用。评论区扣"AI短剧"，我告诉你部署方法。关注我，下期教你怎么投喂自己的剧本，做出你想象中那个故事。

## 脚本二：B站版 | 硬核技术型（3-5 分钟）

> 适合人群：程序员、AI 爱好者、独立开发者
> 调性：技术向、详实、有代码有架构

---

**[片头]**

（黑底白字）"一个人能不能做出一部 AI 短剧？"
（切成 StoryCine Logo + 平台截图）
答案是：能。而且代码已经开源了。

**[第 1 段：为什么要做这个项目 | 30 秒]**

先说一下背景。现在 AI 生图、AI 生视频的能力大家都看到了，Midjourney、Sora 轮番刷屏。但你要把这些能力串起来——从剧本到分镜到生图生视频到合成——变成一个完整的产品，它不是把几个 API 拼在一起那么简单。你要解决工作流编排的问题、资源管理的问题、风格一致性的问题、批量生产的问题。

StoryCine 就是来解决这个的。

**[第 2 段：技术架构 | 60 秒]**

简单说一下技术栈：

前端 Vue 3 + Element Plus，后端 Node.js + Express，数据库 MongoDB，Docker 一键部署。

核心是 AI 引擎部分——用了 LangGraph.js 来做 7 个 Agent 的状态图编排。哪 7 个？标签解析、大纲生成、人物塑造、剧情架构、剧本撰写、剧本续写、剧本校验。一个串一个，上一个 Agent 的输出就是下一个的输入，形成一个完整的 AI 工作流。

生图用的是豆包 Seedream 4.0，支持参考图做角色一致性约束——也就是说你可以先设定一个角色的形象，后面所有镜头里的这个角色都保持同一张脸。生视频用的是 Seedance 2.0，支持图生视频，最多 30 秒。

对，还支持 OpenAI 的最新图片模型 gpt-image-2。

**[第 3 段：怎么部署 | 45 秒]**

开源地址在 GitHub，MIT 协议。部署只需要一条命令：

```bash
git clone 仓库地址 && cd storycine && sh deploy.sh
```

自动搞定前端构建、Docker 镜像打包、全部服务启动。MongoDB + Redis + MinIO 全部 Docker 化，一个端口 3012 对外服务。

当然你得有自己的 API Key——建议优先用豆包，因为生图生视频的能力最完整。DeepSeek 的 API Key 也要一个，用来跑剧本生成的 LLM Agent。

**[第 4 段：实际演示 | 60 秒]**

（屏幕录制全程）

我选"现代都市 + 悬疑"标签，点击生成。这上面有进度实时推送，WebSocket 直连到后端 LangGraph 引擎。大概 2 分钟出完整剧本——注意看，不是那种 AI 废话，它有人物冲突、有剧情转折、有对话。

然后自动拆镜——每一个分镜都有参考构图、景别、运镜方式、建议时长。你可以在时间线上拖拽编辑，也可以让 AI 帮你优化提示词。

接着批量生图——先做参考角色三视图，正面侧面背面一次性出。然后每个分镜根据角色和场景来描述自动生成素材。最后合成，加配乐，导出。

全部，一个人操作，zero 成本。

**[结尾 30 秒]**

这个项目还在持续更新。下一步计划是：配音 TTS 集成、多角色同框生成、字幕自动叠加。

如果你对 AI 创作感兴趣，或者想自己做短剧副业，这个项目可以直接拿来用。代码在 GitHub，给个 Star 支持一下。有问题评论区讨论，我看到会回。
