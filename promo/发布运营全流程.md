# 从零到上架 → 获取流量 完整 SOP

## 第一阶段：准备工作（第 1 天）

### 1.1 设备清单

| 设备 | 最低配置 | 推荐配置 |
|------|---------|---------|
| 电脑 | 16G 内存 + 独立显卡 | 32G + RTX 3060 以上 |
| 麦克风 | 普通领夹麦（¥50） | 罗德 Wireless GO（¥800） |
| 灯光 | 台灯 + 自然光 | 环形补光灯 18 寸（¥150） |
| 手机/相机 | iPhone 后置 / 安卓旗舰 | Sony ZV-E10 / iPhone 15 Pro |
| 支架 | 桌面手机支架（¥20） | 三脚架 + 补光灯一体（¥200） |

### 1.2 软件工具

| 用途 | 推荐工具 | 替代方案 |
|------|---------|---------|
| 视频剪辑 | 剪映专业版（免费） | Premiere / DaVinci Resolve |
| 屏幕录制 | OBS Studio（免费） | 剪映自带录屏 |
| 字幕生成 | 剪映自动识别 | 网易见外 / 飞书妙记 |
| 封面设计 | Canva（免费） | 稿定设计 / Figma |
| 音频处理 | 剪映内置 | Audacity（免费） |
| 提词器 | 剪映提词器 | iPad/手机放旁边 |

### 1.3 环境布置

选择一个**安静、光线充足**的角落：

- **背景**：纯色墙 > 书架 > 窗帘 > 绿幕
- **光线**：面向窗户自然光 > 45° 侧打补光灯
- **收音**：关窗、关空调、关风扇，用领夹麦
- **构图**：人物居中偏上，眼睛在画面 1/3 处，头顶留白不要太多

## 第二阶段：内容制作（第 2-3 天）

### 2.1 三种内容形式选择

| 形式 | 适合平台 | 制作难度 | 流量潜力 |
|------|---------|---------|---------|
| **屏幕录制 + 画外音** | B站、YouTube | ⭐ 低 | ⭐⭐⭐ 中 |
| **真人出镜 + 屏幕混剪** | 抖音、视频号 | ⭐⭐ 中 | ⭐⭐⭐⭐ 高 |
| **纯实拍短剧成片（用工具产出）** | 全部平台 | ⭐⭐⭐ 高 | ⭐⭐⭐⭐⭐ 最高 |

**建议起步路线**：先做屏幕录制版（不用出镜），数据起来后再做真人出镜版。

### 2.2 屏幕录制版制作流程（最快上手）

```
第 1 步：打开 OBS，选择「显示器采集」
第 2 步：打开 StoryCine，提前准备好 demo 数据
第 3 步：按脚本走一遍流程录屏
第 4 步：用剪映导入录屏 + 配音（或 AI 配音）
第 5 步：加速中间等待环节，保留关键步骤
第 6 步：加背景音乐、字幕、转场
第 7 步：导出 1080P 60fps
```

**注意**：录屏时分辨率设为 1920×1080，不要录到桌面图标、微信弹窗等隐私内容。浏览器用无痕模式。

### 2.3 真人出镜版制作流程

```
第 1 步：架好手机/相机，调整构图（上半身即可）
第 2 步：打开提词器，语速控制在一秒 3-4 个字
第 3 步：录制 A-Roll（人物讲述主内容）
第 4 步：录制或准备 B-Roll（产品操作录屏）
第 5 步：导入剪映，A-Roll 为主轨道，B-Roll 叠在上面
第 6 步：用 B-Roll 覆盖 A-Roll 的口误、停顿、废话
第 7 步：添加字幕、BGM、音效、封面
```

**关键技巧**：
- 每个句子之间停顿 0.5 秒，方便后期剪
- 说错了不要停，重说一遍就行，后期剪掉
- B-Roll 覆盖掉 70% 以上的 A-Roll 画面，留声音即可

## 第三阶段：发布上架（第 3-4 天）

### 3.1 平台选择 & 首发策略

| 平台 | 内容形式 | 最佳时长 | 最佳发布时间 | 优先级 |
|------|---------|---------|-------------|--------|
| **抖音** | 竖屏短视频 | 30-60 秒 | 12:00 / 18:00 / 21:00 | ⭐⭐⭐⭐⭐ |
| **B站** | 横屏长视频 | 3-8 分钟 | 12:00 / 17:00 | ⭐⭐⭐⭐ |
| **小红书** | 图文 + 短视频 | 2-3 分钟 | 12:00 / 20:00 | ⭐⭐⭐⭐ |
| **微信视频号** | 竖屏短视频 | 30-60 秒 | 12:00 / 19:00 | ⭐⭐⭐ |
| **YouTube** | 横屏长视频 | 5-15 分钟 | 北京时间 8:00 | ⭐⭐⭐ |
| **GitHub Trending** | README + 截图 | — | 周一/周二 | ⭐⭐⭐ |
| **掘金/CSDN** | 技术文章 | — | 周一/周三上午 | ⭐⭐ |

**首发策略**：同一周内多平台同步发布，利用不同平台的时间差互相导流。

### 3.2 发布检查清单

```
□ 视频封面已制作（大字标题 + 人脸/产品图）
□ 标题包含核心关键词（AI短剧 / 开源 / 一人创业...）
□ 话题标签已添加（5-8 个）
□ 字幕已校对（无错别字，断句合理）
□ BGM 音量不盖过人声（-6dB ~ -8dB）
□ 开头 3 秒有钩子（提问 / 反常识 / 视觉冲击）
□ 结尾有 CTA（关注 / 评论 / 转发）
□ 评论区已准备好引导评论
□ 链接/二维码已放入简介/评论区
```

### 3.3 标题黄金公式

```
🔥 数字 + 结果 + 好奇心
✅ 痛点前置 + 解决方案
💡 身份标签 + 反常识观点
```

**示例**：
- "一个人一天出一集 AI 短剧，我把代码开源了 🔥"
- "做短剧不用养团队了，这个开源项目直接替你搞定剧本+画面+合成"
- "0 预算做短剧是什么体验？我用 AI 做了一部，效果看评论区"

## 第四阶段：获取流量（第 4-14 天）

### 4.1 Day 1-3：冷启动期

| 动作 | 目标 |
|------|------|
| 在 V2EX / 掘金 / 知乎发帖介绍项目 | 获取第一波技术用户 |
| GitHub README 优化（加 demo 截图/GIF） | 提高转化率 |
| 在 AI 相关微信群/QQ 群分享（不发广告，先在群里混脸熟） | 种子用户 |
| B站发视频，标题带"开源"，标签打"AI""编程" | 自然搜索流量 |

### 4.2 Day 4-7：放大期

| 动作 | 目标 |
|------|------|
| 抖音发布第二条视频（用户反馈/案例展示） | 算法推荐叠加 |
| 收集第一条视频的数据，分析完播率、互动率 | 优化下一条 |
| 在 GitHub 提交到 Awesome list / 开源项目推荐 | 长尾流量 |
| 回复每一条评论，引导关注 | 互动率提升 |
| B站动态发项目截图/进展，保持更新节奏 | 活跃度 |

### 4.3 Day 8-14：持续运营

| 动作 | 目标 |
|------|------|
| 每周更新 1-2 条内容（不要求爆款，保持存在感） | 长期积累 |
| 制作"对比类"内容（手工 vs AI、传统流程 vs StoryCine） | 高传播潜力 |
| 用户投稿/二创内容转发 | 社区感 |
| 追踪 GitHub Star 增长曲线 | 里程碑 |

### 4.4 算法核心指标（各平台通用）

```
完播率 > 互动率 > 转发率 > 点赞率 > 收藏率

- 开头 3 秒留住人 → 完播率
- 中间有干货/笑点/悬念 → 互动率
- 结尾有情绪/价值 → 转发率
```

**提升完播率技巧**：
- 每 3-5 秒切一次画面（录屏操作/字幕/转场）
- 用"但是""你看""注意看"做转折
- 提前预告结尾有福利/惊喜

**提升互动率技巧**：
- 故意留一个"小错误"让评论区有人纠正
- 结尾问题引导："你觉得 AI 短剧能替代传统短剧吗？"
- 置顶评论带上 GitHub 链接

## 第五阶段：变现路径

| 方式 | 难度 | 收入潜力 | 适合阶段 |
|------|------|---------|---------|
| GitHub Sponsor / 赞赏 | ⭐ 低 | ¥500-3000/月 | 已有 500+ Star |
| 技术咨询 / 部署服务 | ⭐⭐ 中 | ¥5000-2W/月 | 已有用户基础 |
| AI 短剧代制作 | ⭐⭐ 中 | ¥2000-1W/单 | 有成品案例 |
| 知识付费 / 教程 | ⭐⭐ 中 | ¥1W-5W/月 | 已有流量 |
| SaaS 化收费 | ⭐⭐⭐ 高 | 量大 | 产品成熟后 |

**建议起步路径**：先用免费内容积累口碑 → GitHub Star 破千 → 推出付费部署/定制服务 → SaaS 化。

## 附：视频制作时间估算

| 环节 | 屏幕录制版 | 真人出镜版 |
|------|-----------|-----------|
| 脚本撰写 | 30 分钟 | 1 小时 |
| 环境布置 | 5 分钟 | 30 分钟 |
| 录制素材 | 20 分钟 | 1.5 小时（含 NG） |
| 剪辑 + 字幕 | 1 小时 | 2-3 小时 |
| 封面制作 | 10 分钟 | 10 分钟 |
| 发布 + 运营 | 15 分钟 | 15 分钟 |
| **合计** | **约 2.5 小时** | **约 5-6 小时** |

第一次做建议预留 2 倍时间，熟练后可以压缩到一半。
